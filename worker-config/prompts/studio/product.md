## Phase: Product (docs/PRODUCT.md)

Define the product from the brief and the research.
- One-line pitch, positioning against the competitors that matter, and personas (1-3, concrete).
- **Business model**: free, one-off, subscription, or personal use only, with the reasoning.
- **Feature list** ranked MoSCoW (must / should / could / later), each with a one-line user value. Keep the MVP small:
  what makes it worth using daily, nothing more.
- **User stories** for the MVP (5-12), each with testable acceptance criteria.
- **Non-goals** for v1, and **metrics**: what to measure, so analytics can be built in from the start.
This document becomes docs/PRODUCT.md in the repo. Builders follow it literally, so be precise.
